## [Unreleased]

### Added
- Follow-up board CLI (`add`, `ls`, `show`, `edit`, `touch`, `done`, `reopen`, `rm`, `resume`).
- Jobs (epic, story, task, bug, spike, idea, misc) and agent sessions as groupings, with
  `fu job`, `fu sessions` and `fu tree`.
- Interactive board: filterable Board view, Jobs folder-tree view, in-app help (`h`).
- `fu skill install` to link the bundled follow-ups skill into Claude Code and Copilot CLI.
